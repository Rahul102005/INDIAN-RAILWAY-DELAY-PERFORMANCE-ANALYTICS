Indian Railway – Delay & Performance Analytics 🚆

📌 Project Overview

Indian Railway – Delay & Performance Analytics is a data visualization project designed to analyze train delays, punctuality, passenger counts, train types, and travel distances.

The dashboard helps users understand railway performance through interactive charts, key performance indicators (KPIs), and filters.

📊 Dashboard KPIs

- Total Trains: 10K
- Average Delay: 22.91
- On-Time Percentage: 11.29%
- Delayed Trains:9K
- Total Stations:18
- Total Distance:14M

Note: These values are taken from the dashboard screenshot and may change when filters are applied.

📈 Dashboard Visualizations

The dashboard includes the following charts:

1. Average Delay by Train Name** – Compares average delays across different trains.
2. Passenger Count by Train Type** – Shows passenger counts for different train categories.
3. Total Trains by Train Type** – Displays the distribution of trains by type.
4. Passenger Count by Date** – Shows passenger-count trends over time.
5. Average Delay by Date** – Analyzes changes in average train delays over time.

🎛️ Interactive Filters

The dashboard provides the following filters:

- Date
- Origin
- Train Type
- Destination

These filters allow users to analyze railway performance for specific dates, routes, and train categories.
